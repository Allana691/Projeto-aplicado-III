# Cronograma do Projeto

Este documento apresenta o planejamento e o acompanhamento das atividades desenvolvidas durante o Projeto Aplicado III – Sistema Híbrido de Recomendação de Cursos para Desenvolvimento Profissional.

O cronograma está dividido em duas partes:

- **Cronograma Planejado:** apresenta as atividades, responsáveis, prazos e resultados esperados para o desenvolvimento do projeto.
- **Cronograma Real:** registra a execução efetiva das atividades, permitindo acompanhar o andamento do projeto e eventuais alterações em relação ao planejamento inicial.
