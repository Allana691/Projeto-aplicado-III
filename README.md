## Sobre o projeto

O projeto propõe o desenvolvimento de um sistema híbrido de recomendação de cursos voltado ao desenvolvimento profissional, utilizando dados da Escola Virtual de Governo (EV.G).

A proposta combina técnicas de recomendação baseada em conteúdo e filtragem colaborativa para gerar recomendações personalizadas de acordo com os interesses, perfil e histórico de interações dos usuários.

## Base de dados

Serão utilizados dados públicos disponibilizados pela Escola Virtual de Governo (EV.G), incluindo:

- Catálogo de cursos;
- Histórico de matrículas e interações dos usuários.

Os dados serão utilizados para identificar características dos cursos e padrões de comportamento que possam apoiar a geração de recomendações.

## Abordagem

O sistema será desenvolvido utilizando uma abordagem híbrida, combinando:

- Recomendação baseada em conteúdo (Content-Based Filtering);
- Filtragem colaborativa (Collaborative Filtering).

As técnicas e algoritmos utilizados serão definidos e avaliados durante o desenvolvimento do projeto.

## Objetivo extensionista

O sistema será aplicado junto à comunidade para gerar recomendações de cursos de acordo com interesses, conhecimentos e objetivos profissionais dos participantes.

A proposta está relacionada aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU:

- **ODS 4 – Educação de Qualidade**
- **ODS 8 – Trabalho Decente e Crescimento Econômico**

A aplicação busca facilitar o acesso a oportunidades gratuitas de capacitação e apoiar o desenvolvimento de conhecimentos e competências profissionais.
