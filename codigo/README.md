# Código

Esta pasta será destinada aos códigos desenvolvidos durante a implementação do sistema híbrido de recomendação de cursos.

Ao longo do projeto, serão armazenados aqui os scripts e demais arquivos utilizados nas etapas de:

- exploração e preparação dos dados;
- processamento e consultas às bases;
- desenvolvimento do sistema de recomendação;
- treinamento e avaliação dos modelos;
- geração das recomendações.

A organização interna desta pasta será atualizada conforme o desenvolvimento técnico do projeto.
