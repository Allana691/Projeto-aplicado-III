# Dados

Esta pasta reúne informações e arquivos relacionados às bases de dados utilizadas no desenvolvimento do sistema de recomendação.

## Fontes de dados

O projeto utiliza dados públicos da Escola Virtual de Governo (EV.G), incluindo:

- Catálogo de cursos;
- Histórico de matrículas e interações dos usuários.

Devido ao grande volume dos dados originais, os arquivos de maior tamanho não serão armazenados diretamente neste repositório.

Nesta pasta poderão ser disponibilizados arquivos derivados, amostras, dados processados e demais materiais necessários para documentar a preparação dos dados utilizada no projeto.
