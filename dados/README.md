# Dados

Esta pasta reúne informações e arquivos relacionados às bases de dados utilizadas no desenvolvimento do sistema de recomendação.

## Fontes de dados

O projeto utiliza dados públicos da Escola Virtual de Governo (EV.G), mantida pela Escola Nacional de Administração Pública (Enap).

### 1. Catálogo de cursos da EV.G

O catálogo contém informações sobre os cursos disponibilizados pela plataforma, incluindo características que poderão ser utilizadas na abordagem baseada em conteúdo do sistema de recomendação.

**Arquivo utilizado:** `catalogo.csv`

**Fonte:** Escola Virtual de Governo (EV.G)  
https://www.escolavirtual.gov.br/catalogo

### 2. Base de matrículas da EV.G

A base contém dados relativos às matrículas realizadas na Escola Virtual de Governo (EV.G), incluindo informações sobre usuários, cursos e situação das matrículas. Esses dados serão utilizados para analisar o comportamento dos usuários e apoiar o desenvolvimento do sistema de recomendação.

**Arquivo utilizado:** `20260902_escolavirtual_dadosabertos_matriculas_utf8.csv`

**Fonte:** EV.G em Números – Dados Abertos  
https://emnumeros.escolavirtual.gov.br/dados-abertos/

## Armazenamento dos dados

Devido ao grande volume dos dados originais, especialmente da base histórica da EV.G, os arquivos de maior tamanho não serão armazenados diretamente neste repositório.

Nesta pasta poderão ser disponibilizados arquivos derivados, amostras, dados processados e demais materiais necessários para documentar a preparação dos dados utilizados no projeto.
